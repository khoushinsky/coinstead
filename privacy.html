Plain-language policy

Privacy, without the fine-print fog.

Coinstead is designed to keep financial records local and put sharing decisions in your hands. This policy explains exactly what the app stores, which optional actions can send information elsewhere, and what Coinstead does not collect.

1. Scope

This policy covers the Coinstead iPhone app and this website. Coinstead is free, requires no account, and contains no advertising. The app is built as a personal, local-first financial-information tool.

“Local-first” means Coinstead’s normal records are stored on your device and the app does not operate a Coinstead cloud account or synchronization service. It does not mean information can never leave the device: exports, backups, external links, the iOS share sheet, support email, and the optional ChatGPT handoff are controlled exceptions explained below.

2. Data stored locally

Coinstead stores the information needed to provide its features in an SQLite database inside the app’s private iOS container. Depending on what you use, this can include:

  • transaction dates, descriptions, normalized merchant names, amounts, directions, categories, notes, account labels, and classification status;
  • statement metadata such as the filename, file type, import date, statement period, account label, a content hash used to prevent duplicate imports, and related transaction identifiers;
  • income entries, starting savings and investment balances, monthly housing expenses, categories, allocation goals, recurring plan items, debts, and debt-plan settings;
  • merchant-matching rules, category preferences, pending classification suggestions, and records of categories you intentionally deleted;
  • saved Garden Planning purchase scenarios and the assumptions entered for them; and
  • app preferences and local setup state.

This data is used on-device to calculate summaries, compare activity with your goals, detect duplicate imports, classify merchants, preserve review progress, estimate debt timelines, and run purchase illustrations.

3. Statement imports

Coinstead can read CSV files, plain-text files, and PDFs that contain extractable text. When you choose a statement, the app reads the file and parses it on the device. The local database stores extracted transaction information and statement metadata; it does not store the original statement file itself.

If you open a supported statement through the iOS share sheet, iOS provides Coinstead with a private temporary Inbox copy. Coinstead reads that copy and deletes it from the app’s temporary Inbox. It does not delete the original statement in Files, Downloads, email, or another storage provider.

If you import through Coinstead’s file picker, the selected source file remains where you stored it. Coinstead accesses it using iOS document permissions only long enough to read it.

A text-readable PDF is different from a scanned image. Coinstead does not send scans to an external optical-character-recognition service.

4. Automatic and manual categorization

Coinstead first uses local rules: built-in merchant patterns, categories you keep active, merchant mappings you edit, and your prior confirmed categorizations. These checks do not require a network connection.

Transactions are saved before review. If a category is unresolved, the transaction can temporarily use “Other” while remaining in the Review tab. Confirming a category updates the existing local record; it does not create a second transaction. Pending suggestions and review progress are also stored locally so you can stop and return later.

5. Apple Intelligence

On a compatible iPhone with a supported version of iOS, you may ask Apple Intelligence to suggest categories for unresolved transactions. Coinstead uses Apple’s Foundation Models framework and the device’s on-device language model.

For this classification task, Coinstead provides the model with unresolved merchant descriptions, normalized merchant text, transaction type, and the names of your active categories. It does not provide the original statement file. Coinstead requests suggestions in small batches, stores the returned suggestions locally, and waits for you to approve or reject them.

Apple Intelligence availability and system behaviour are controlled by Apple and your device settings. Apple’s handling of Apple services is described in the Apple Privacy Policy.

6. Optional ChatGPT handoff

Coinstead does not call the OpenAI API or send data to ChatGPT automatically. The handoff begins only when you choose to share a classification request or copy it and open ChatGPT.

The generated request contains all unresolved transaction descriptions and the names of your active Coinstead categories. It does not include transaction amounts, dates, balances, account labels, or the original statement file. If a merchant description itself contains personal information, that text will still be present.

Using “Share Classification Request” opens the iOS share sheet, where you choose the receiving app or person. Using “Copy Request & Open ChatGPT” places the request on the system clipboard and opens chatgpt.com. Clipboard content can remain available to the operating system and other permitted apps until it is replaced or cleared.

Anything you send to ChatGPT or another destination is governed by that recipient’s terms and privacy practices, including the OpenAI Privacy Policy. You paste the response back into Coinstead; the resulting suggestions are stored locally and remain subject to your review.

7. Network communication

The Coinstead iPhone workflow has no Coinstead-operated server, user account, cloud-sync service, advertising connection, or analytics endpoint. It does not automatically upload financial records to the developer.

Network activity can occur when you deliberately:

  • open ChatGPT for the optional handoff;
  • open educational links to Government of Canada resources from the app;
  • save or share an export through a cloud-storage provider, email app, or another destination you select; or
  • send a support email.

Apple may also provide App Store delivery, operating-system services, Apple Intelligence availability, and device backups under your Apple settings and Apple’s policies. Those services are not Coinstead servers.

8. Exports, backups, and restore files

Coinstead can create a full backup and a transaction CSV export. A full backup can contain categories, goals, merchant rules, income, recurring plan items, starting balances, debt information, statement metadata, transactions, and other settings needed for restoration. A transaction CSV contains transaction details.

You choose the destination using Apple’s document and share interfaces. If you save to iCloud Drive, another cloud provider, email, or a third-party app, that provider receives the file under its own privacy terms. Coinstead does not control copies after export.

Restoring a backup reads the file you select and replaces the app’s local financial records with the backup contents after confirmation.

9. App lock and device backups

You may enable Coinstead’s optional app lock. Authentication is handled by iOS using Face ID or the device passcode. Coinstead receives only the success or failure result; it does not receive or store your face data or passcode.

The app lock is an access gate, not a claim that Coinstead separately encrypts its database. Device-level protections are provided by iOS and depend on your passcode, device, and system settings.

Coinstead does not implement cloud sync. However, iOS device backups may include app data according to your iCloud or computer-backup settings. Apple controls that backup process.

10. Retention, deletion, and your control

Local records remain on your device until you edit or delete them, use “Delete All Financial Data” in Settings, or remove the app and its data through iOS. Coinstead does not set a remote retention period because it does not receive a remote copy of those records.

Deleting app data does not delete backup or export files you previously saved elsewhere, information you shared with another app, clipboard history maintained by the system, support emails, or copies included in device backups. Those must be managed at their destination.

Coinstead lets you delete transactions, categories, saved scenarios, and other records through the relevant app interfaces. Deleting a category does not delete its transactions; you can reassign them or leave them uncategorized.

11. Support messages

If you email support, the email address, message, and any attachments you choose to send leave Coinstead and are delivered to the developer’s personal Gmail inbox. They are processed by the email services used by you and the developer and are used to understand and respond to your request.

Support messages are archived after the request has been handled. Archiving is not deletion: an archived message remains stored in the Gmail account until it is later deleted and may remain in service-provider backups according to the provider’s retention practices.

Please do not attach bank statements, backups, full transaction exports, account numbers, passwords, or other sensitive financial information. A redacted screenshot and the app/iOS version are usually more useful.

12. This website

This site uses static HTML, CSS, and a small local script for navigation. Coinstead does not place analytics, advertising pixels, tracking scripts, external fonts, or application cookies on the site.

If this site is hosted on GitHub Pages, GitHub receives ordinary web requests and may process technical information such as IP address, browser information, requested pages, and timestamps under the GitHub General Privacy Statement. GitHub may also make aggregate repository or site traffic information available to the repository owner.

13. Financial information, not advice

Coinstead provides financial information and goal-based illustrations. It does not provide financial, investment, tax, accounting, or legal advice; decide what you can afford; recommend a specific investment; or guarantee an outcome.

Scores describe alignment with the goals and data you enter, not an objective measure of financial health. Debt estimates and Garden Planning projections rely on stated assumptions and can differ from real outcomes. Garden Planning is intended for everyday purchases and personal loans, not mortgages, and does not include mortgage-specific costs or lending requirements.
